🔄 No-IP Dynamic DNS Update Script (Bash/Powershell)
This lightweight and dependency-free Bash/Powershell script automatically updates your No-IP Dynamic DNS hostname with your current public IP address. It's ideal for home servers, dynamic IP environments, or any system behind a residential ISP where the external IP changes frequently.

✨ Features
✅ Simple and portable — just one shell script

🔐 Uses HTTP Basic Authentication with your No-IP credentials

🌐 Detects public IP using reliable online services

📡 Sends secure update requests to dynupdate.no-ip.com

🛠️ Customizable User-Agent for easy tracking

🕒 Easily integrate with cron or systemd for automated updates
